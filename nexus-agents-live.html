⚙️ الإعدادات

وضع الاتصال الحالي: —
داخل معاينة claude.ai، الاتصال بـ Claude يشتغل تلقائياً بدون إعداد. لو نشرت هذا التطبيق كموقع أو تطبيق مستقل، لازم تشغّل سيرفر الـ backend الخاص فيك (راجع ملفات nexus-backend) وتحط رابطه هون.

📚 قاعدة المعرفة

أضف حقائق أو سياقات ثابتة (عن مشروعك، شركتك، تفضيلاتك) ليستخدمها كل الوكلاء تلقائياً في ردودهم.

📜 سجل النشاط

اختر وكيلاً واحداً (أو فعّل الذكاء الجماعي واختر أكثر من وكيل)، ثم اكتب سؤالك بالأسفل.
كل رد يُولَّد فعلياً عبر Claude API — لا محتوى مُحاكى.
