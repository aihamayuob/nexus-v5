# NEXUS AGENTS — Backend

سيرفر خفيف (Node.js + Express) مهمته الوحيدة: حمل مفتاح Anthropic API بأمان، وتمرير طلبات التطبيق الأمامي (nexus-agents-live.html) إليه.

## لماذا هذا ضروري؟

الملف الأمامي (HTML/JS) يشتغل داخل متصفح المستخدم، وأي شخص يقدر يفتح "أدوات المطور" ويشوف أي مفتاح API مكتوب مباشرة بالكود. لهذا **لا يجوز أبداً** وضع مفتاح Anthropic الحقيقي داخل ملف HTML يُنشر للمستخدمين. هذا السيرفر يحل المشكلة: المفتاح موجود فقط على السيرفر، وواجهة المستخدم تكلّم السيرفر بس.

## التشغيل محلياً

```bash
cd nexus-backend
npm install
cp .env.example .env
# افتح .env وحط مفتاح Anthropic API الحقيقي فيه
npm start
```

السيرفر رح يشتغل على `http://localhost:3000`.

## ربطه بالواجهة الأمامية

بملف `nexus-agents-live.html`، افتح إعدادات التطبيق (⚙️) وحط رابط السيرفر (مثلاً `http://localhost:3000` وقت التجربة المحلية، أو رابط استضافتك الحقيقي بعد النشر).

## النشر الحقيقي (Production)

خيارات سهلة ورخيصة للاستضافة:
- **Render.com** أو **Railway.app**: نشر مباشر من GitHub، طبقة مجانية محدودة كافية للتجربة.
- **Fly.io**: مناسب لو حبيت تحكم أكبر بالسيرفر.

خطوات عامة:
1. ارفع هذا المجلد لمستودع GitHub.
2. اربطه بالمنصة المختارة، وحدد `ANTHROPIC_API_KEY` كـ Environment Variable من لوحة التحكم (**ليس بالكود**).
3. بعد النشر، خذ الرابط العام (مثلاً `https://nexus-backend.onrender.com`) وحطه بإعدادات الواجهة الأمامية.

## نقاط أمان مهمة قبل الإطلاق التجاري

- فعّل CORS بحيث يسمح فقط بدومين تطبيقك الحقيقي، مو `*`.
- استبدل الـ rate limiting البسيط (in-memory) بحل حقيقي مثل Redis إذا كان عندك أكثر من سيرفر واحد.
- أضف مصادقة مستخدمين (تسجيل دخول) قبل ما تسمح بالوصول للـ endpoint، وإلا أي حد يعرف رابط السيرفر ممكن يستهلك رصيدك من Anthropic.
- راقب الاستهلاك (tokens) بشكل دوري عشان ما تتفاجأ بفاتورة كبيرة.
