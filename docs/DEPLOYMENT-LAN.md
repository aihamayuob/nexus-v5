# NEXUS — تشغيل الإصدار الأول (محلي / شبكة محلية موثوقة) — خطوات وحدود أمنية

**الحالة: للاستخدام المحلي أو على شبكة محلية (LAN) موثوقة فقط. هذا الإصدار غير مناسب للتعرّض لشبكة الإنترنت العامة.**
لا يوجد TLS في الحزمة، ولا هوية متعددة المستأجرين، ولا حماية من حجب الخدمة على مستوى الشبكة. كل ما يلي موثّق بمصدره في `baseline/evidence/release-v1-*`.

## 2) خطوات التشغيل

### أ) جهاز واحد (الموصى به والمُتحقَّق منه)
المتصفح والواجهة والخلفية على نفس الجهاز. هذا هو الوضع الوحيد الذي يعمل فيه التطبيق كاملًا (انظر §4).

```bash
cd src-baseline/nexus-backend
npm ci
npm run build
# اختياري لكن مستحسن حتى محليًا:
export NEXUS_GATEWAY_KEYS="$(node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))")"
export NEXUS_CORS_ORIGINS="http://localhost:8080"      # أصل الواجهة بالضبط (المضيف + المنفذ)
NEXUS_HOST=127.0.0.1 npm start                          # 127.0.0.1 هو الافتراضي أصلًا
```
في طرفية أخرى قدّم الواجهة كملفات ثابتة عبر HTTP (ملفات ES modules لا تعمل من `file://`):
```bash
cd frontend && python3 -m http.server 8080 --bind 127.0.0.1
```
افتح `http://localhost:8080/neural_nexus_ai_agents-4-3-5-3.html` (لا يوجد `index.html`)، ثم الإعدادات ⚙️ → ضع رابط الخلفية `http://127.0.0.1:8787` والمفتاح. **المفتاح يُحفظ في ذاكرة الصفحة فقط؛ ستعيد إدخاله بعد كل إعادة تحميل (سلوك مقصود).**
(أصل الواجهة `localhost` يختلف نصًا عن `127.0.0.1`؛ CORS يطابق النص حرفيًا.)

### ب) تعريض الخلفية للشبكة المحلية (مفاتيح إلزامية)
```bash
export NEXUS_HOST=0.0.0.0            # أو عنوان LAN للجهاز
export NEXUS_GATEWAY_KEYS="<مفتاح ≥16 حرفًا>[,<مفتاح آخر>]"
export NEXUS_CORS_ORIGINS="<أصل الواجهة بالضبط>"
npm start
```
- بدون `NEXUS_GATEWAY_KEYS` صالح **يرفض الخادم الإقلاع** (لا يوجد خيار تجاوز).
- كل المفاتيح المضبوطة متساوية الصلاحية (نشر أحادي المستأجر بقرار مالك المشروع).
- لا تضع مفتاحًا حقيقيًا في ملف يُلتزَم به. `.env` مُتجاهَل في git؛ `.env.example` يحوي قيمة فارغة فقط.

## 3) حدود أمنية صريحة (لا تُخفى)
1. **HTTP عادي**: مفتاح البوابة يمرّ على الشبكة **بلا تشفير**. يفترض الإصدار شبكة محلية موثوقة. لا تعرّضه للإنترنت.
2. **CSP عبر `<meta>`** وتحتوي `'unsafe-inline'` للسكربت والأنماط (الملف الأحادي فيه سكربت مضمّن وعشرات معالجات `onclick`). أي أنها **لا تمنع XSS عبر سكربت مضمّن**؛ تمنع السكربتات/الكائنات/الإطارات/`base`/وجهات النماذج الغريبة فقط. `connect-src` يسمح بـhttp(s)/ws(s) لأن رابط الخلفية يضبطه المستخدم.
3. `frame-ancestors` وHSTS و`report-uri` **لا يمكن** ضبطها من `<meta>`؛ تحتاج الخادم الذي يقدّم ملف الـHTML (غير موجود في الحزمة). الخلفية ترسل HSTS وCSP صارمة على استجابات الـAPI فقط.
4. `X-Forwarded-For` **يُتجاهل افتراضيًا** (F06-a، 2026-11-16): هوية العميل = عنوان الاتصال الفعلي. لا يُحترم إلا إذا كان الطرف المتصل مدرجًا صراحةً في `NEXUS_TRUST_PROXY` (عناوين IP أو IPv4 CIDR؛ لا wildcard)، ويؤخذ أقرب عنصر غير موثوق من اليمين. *(الوضع السابق: يُصدَّق دائمًا ويمكن تزويره لتجاوز محدّد المعدّل في وضع بلا مفاتيح.)*
5. وسيط MQTT (إن فعّلته بـ`NEXUS_MQTT_PORT`، الافتراضي معطّل) يستمع على كل الواجهات بمصادقة لكل جهاز؛ لم يُشدَّد في هذا الإصدار.
6. المفتاح في الذاكرة فقط: لا يُشارَك بين تبويبين، ويُفقد عند التحديث. المفتاح القديم المخزَّن من إصدارات سابقة **يُحذف عند الإقلاع ولا يُتبنّى**.
7. تنفيذ الشيفرة (sandbox) معطّل افتراضيًا ولا يُعدّ حدًّا أمنيًا حقيقيًا إن فُعِّل (انظر توثيق الخلفية).
8. `sw.js` مُؤلَّف حديثًا (لا استرجاع للأصل). لا يخزّن مفاتيح ولا ترويسات ولا يلمس `/api` أو `/v2`.

## 4) عائق معروف: الجهاز الآخر على الـLAN عبر HTTP عادي (BLOCKED)
قياس فعلي (Chromium 141، خادم ثابت على `0.0.0.0`):

| العنوان | `isSecureContext` | `crypto.subtle` | Service Worker | الإقلاع (`autoInitApp`) |
|---|---|---|---|---|
| `http://127.0.0.1:<port>` | true | true | true | **نجح** |
| `http://192.0.2.2:<port>` (عنوان غير loopback) | false | **false** | false | **لم يكتمل** |

المتصفحات تعطّل WebCrypto وService Worker خارج «السياق الآمن» (HTTPS أو localhost). التطبيق يعتمد على WebCrypto في إقلاعه، لذا **فتح الواجهة من جهاز آخر عبر `http://<LAN-IP>` لا يعمل**. هذا سلوك سابق لهذا الإصدار (نفس النتيجة على الشجرة قبل B4) وليس من تغييراتنا.
اتجاهات ممكنة (غير مُنفَّذة ولا مُختبَرة هنا): وكيل عكسي بـHTTPS (شهادة موثوقة على الجهاز) يقدّم الواجهة ويمرّر `/api` و`/v2` إلى خلفية مربوطة على `127.0.0.1` (فلا حاجة لتعريض الخلفية للشبكة أصلًا)؛ أو علم متصفح للتجارب فقط. لا نصف أيًّا منها بأنه «مدعوم» قبل اختباره.

## 5) قبل فتح المنفذ على الشبكة — قائمة تحقق
- [ ] `NEXUS_GATEWAY_KEYS` مضبوط، ≥16 حرفًا، غير مُلتزَم به في git.
- [ ] `NEXUS_CORS_ORIGINS` = أصل الواجهة بالضبط (ليس `*`).
- [ ] الشبكة موثوقة، ولا إعادة توجيه منافذ من الراتر إلى الإنترنت.
- [ ] تعلم أن المفتاح يسافر بلا تشفير على HTTP.
- [ ] لا تفعّل `NEXUS_ENABLE_CODE_EXECUTION_TOOL` ما لم تفهم حدّه.
