# NEXUS — نشر على VPS بأمر واحد (حزمة جاهزة، لم تُنفَّذ على خادم حقيقي بعد)

**الحالة:** `setup.sh` = **PARTIAL**: صياغة bash ✓، فحص المدخلات ✓ (6 حالات)، صياغة وحدة systemd ✓، تعبير فحص Node ✓. **لم يُشغَّل على خادم حقيقي (UNVERIFIED)**، ولم يُختبر nginx/certbot/ufw هنا. لا أستطيع الاتصال بخادمك (بيئتي بلا SSH)، فالتنفيذ على الخادم بيدك ثم تلصق لي المخرجات (بدون مفاتيح) فأشخّص.

## ما لا أستطيع فعله نيابةً عنك (وهو بيدك فقط)
إنشاء حساب الاستضافة وإدخال الهوية والموافقة على الفوترة وشروط الخدمة والمصادقة الثنائية، وشراء النطاق، وإنشاء مفاتيح المزودين. لا يوجد «رابط» أمنحه لي لهذه الموافقات — كل منها يتم في صفحة المزود نفسه.

## خطواتك (≈30 دقيقة)
1. **مزود VPS:** أي مزود يقدّم Ubuntu 24.04 LTS بـ1 vCPU و1–2 GB RAM على الأقل. تأكد قبل الدفع أن المزود يقبل بلدك ووسيلة الدفع لديك. فعّل المصادقة الثنائية على الحساب.
2. **النطاق:** سجّل نطاقًا (أو نطاقًا فرعيًا) وأنشئ سجل **A** يشير إلى عنوان IP للخادم، وانتظر حتى يُحَل (`getent hosts نطاقك`).
3. **ادخل بـSSH** (يفضّل بمفتاح SSH) ونفّذ:
```bash
sudo apt-get update && sudo apt-get install -y git
sudo git clone --branch review/r4-backend-html https://github.com/aihamayuob/nexus-v5 /opt/nexus
sudo DOMAIN=نطاقك EMAIL=بريدك ACCEPT_LETSENCRYPT_TOS=yes BUDGET_USD=5 bash /opt/nexus/deploy/vps/setup.sh
```
   `ACCEPT_LETSENCRYPT_TOS=yes` = موافقتك أنت على اتفاقية Let's Encrypt (https://letsencrypt.org/repository/)؛ السكربت يرفض العمل بدونها.
4. السكربت يطبع **مفتاح البوابة مرة واحدة** ورابط الصفحة. افتح `https://نطاقك/NEXUS-Standalone.html` → تبويب الاتصال: عنوان API = `https://نطاقك` + المفتاح.
5. **مفاتيح المزودين بنفسك:** أنشئها من لوحات المزودين وفعّل **حدّ إنفاق داخل لوحة كل مزود**، ثم على الخادم: `sudo nano /etc/nexus/env` (أزل `#` وضع المفتاح) ثم `sudo systemctl restart nexus`. لا تلصقها في أي دردشة.
6. **التحقق الحقيقي** على الخادم: `cd /opt/nexus && NEXUS_ANTHROPIC_API_KEY=… node e2e/real-provider-validation.mjs` (يقرأ المفاتيح من البيئة ولا يطبعها).

## ما يبنيه السكربت
nginx يقدّم الصفحة ويمرّر `/api /v2 /health` فقط (**ليس `/mcp`**) مع حد معدّل على الحافة (10 طلب/ث، burst 40)؛ XFF الوارد يُستبدل بعنوان النظير؛ الخلفية على 127.0.0.1 تحت مستخدم غير مميّز وsystemd مع `NoNewPrivileges`؛ مفتاح بوابة مولَّد؛ سقف `NEXUS_DAILY_BUDGET_USD`؛ CORS = نطاقك فقط؛ ufw: SSH و80 و443؛ شهادة Let's Encrypt بتجديد تلقائي من حزمة certbot.
(الـTLS هنا ينهيه nginx — إعداد سبق التحقق من نسخته المحلية في `docs/DEPLOYMENT-TLS.md`. TLS الداخلي في الخلفية متاح أيضًا لكنه لا يقدّم الصفحة ويحتاج إعادة تشغيل عند تجديد الشهادة، لذا لم أستعمله هنا.)

## حدود صريحة
- نموذج مفتاح واحد مشترك لمستأجر واحد: من يعرف المفتاح يستهلك ميزانيتك. لا مصادقة لكل مستخدم، لا WAF، لا مراقبة/نسخ احتياطي مُعدّة — راجع `docs/PUBLIC-DEPLOYMENT-READINESS.md`.
- الصفحة المنشورة تعمل بنمط محاكاة DEMO أيضًا؛ التشغيل الحي يحتاج مفتاحك ومزودًا حقيقيًا.
- أبقِ MQTT وتنفيذ الشيفرة معطّلين (الافتراضي).
